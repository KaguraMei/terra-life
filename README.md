# 泰拉人生模拟

在《明日方舟》的泰拉世界里随机出生，经历一次只属于你的完整人生。

你可能出生在移动城市，也可能出生在荒野；可能成为普通工人、术师、医生或罗德岛干员，也可能在天灾、战争、矿石病和贫困中挣扎。每一年选择一个生活重心，遇到抉择时亲自决定，然后看这条人生会走向哪里。

这是一个非商业同人项目，世界观与专有名词来自《明日方舟》。人生模拟框架和首页交互参考 [80億分之1 / 1 in 8 Billion](https://1in8b.life/zh/)。

## 先玩起来

### 浏览器直接打开

双击 `index.html` 即可运行。项目使用普通 HTML、CSS 和 JavaScript，不需要安装前端框架，也不要求联网。

### 使用本地服务器

如果浏览器限制了 `file://` 页面，打开终端运行：

```bash
node tools/serve.mjs 8814
```

然后访问 <http://127.0.0.1:8814/>。

## 游戏流程

1. 在首页选择出生抽签口径。默认按“此刻出生的婴儿”抽签，也可以按“此刻活着的所有人”抽签。
2. 直接点击“出生”，或在高级设置中指定国家、种族、性别和随机种子。
3. 出生登记完成后点击“开始这一生”。登记动画只展示结果，不会额外改变模拟随机数。
4. 游戏中为每一年选择生活重心，例如求学、工作、休养或经营关系。
5. 遇到抉择时可以暂停阅读并选择行动；开启“自动选择”后，游戏会替你选择年度重心和抉择选项。
6. 人生结束后查看一生纪要、主要事件、四维变化、财产曲线和矿石病记录。

“快转到下一个抉择”会跨年推进，保留途中事件，直到出现需要你回答的抉择或人生结束。相同版本、种子、开局设置、选择和年度重心时机才能复现同一局；种子本身只确定起点与随机序列。

## 抽签与数据口径

出生地有两种抽签方式：

- **此刻出生的婴儿**：按各地年出生权重抽签，适合观察“一个新生儿更可能来自哪里”。
- **此刻活着的所有人**：按人口权重抽签，适合观察“随机遇到一个泰拉居民”。

当前人口快照已将《大地巡旅》中能核对到页码的数字写入，并把未找到明确数字的国家标为推断；高卢的历史遗民不计入当前抽签。详见[人口数据快照](docs/data/population-2026-10-19.json)。年出生权重、寿命、婴儿死亡率、矿石病感染率、天灾频率和职业风险仍属于模拟假设。

组织相关事件设有统一的游戏年代门槛；其中尚未核实的年份不代表官方成立日期。本轮人口与死因修正记录见[修正说明](docs/人口与死因修正-2026-10-19.md)。

因此，游戏中的概率和平均寿命应当理解为“本模拟里的泰拉”，不是现实人口统计，也不是官方数值。详细来源、假设和模型边界见 [`docs/`](docs/)。

## 隐私与本地记录

- 项目不把人生记录上传到服务器，也没有账号系统。
- 已结束人生的摘要保存在当前浏览器的 `localStorage` 中；清理站点数据会删除这些记录。
- 进行中的人生不保存进度，返回首页或关闭页面后不能断点续玩。
- 随机种子可以用于复现或分享一局，但它不是云端存档。
- 页面中的地图是出生地分布示意，不是官方疆域图。

## 分享一局

可以把参数附在网址后面，用来复现特定起点：

```text
?go=1&nation=YAN&race=sarkaz&sex=F&seed=demo
```

常用参数：

```text
?mode=birth       抽签口径：birth 或 pop
?nation=YAN       指定出生国家
?race=sarkaz      指定种族
?sex=F            指定性别：M 或 F
?seed=demo        指定随机种子
?auto=1           开局后启用自动模式
?speed=8          初始播放速度
?by=1070          指定泰拉历出生年份
```

开发和诊断参数可能随版本调整，不保证长期兼容。

## 反馈问题时请附上

请尽量提供：

- 浏览器和设备（电脑或手机）；
- 复现步骤；
- 出现问题的年龄、事件或抉择；
- 页面网址中的参数和随机种子；
- 如果可以，附一张截图或浏览器控制台错误。

这样可以区分随机结果、内容设计和真正的程序错误。

## 维护者检查

在项目根目录运行：

```bash
node tools/verify.mjs
node tools/verify-birth.mjs
node tools/verify-reliability.mjs
node tools/verify-events.mjs 1000
node tools/headless.mjs
```

这些命令检查结构与引用、出生流程、自动模式与记录边界、事件可达性和批量人生模拟。本轮结果见[执行与验收记录](docs/本轮执行与验收-2026-10-18.md)。

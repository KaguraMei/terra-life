# 泰拉人生模拟 · Terra Life Sim

在《明日方舟》的泰拉世界随机出生，把一次的人生活到最后。

模拟框架移植自 **[80億分之1 / 1 in 8 Billion](https://1in8b.life/zh/)** 的人生模拟内核，
并针对泰拉重新建模了国家、种族、职业、死因与**矿石病**。

### 首页与出生流程（2026-10-17）

首页已按当天的原作官网重新设计：浅灰绿底、两栏大标题、酒红色出生按钮、点阵分布图与概率条。自定义国家、种族、性别和种子保留在展开设置中。

点击「出生」后依次进入 **26 次减速地名轮播 → 出生登记卡 → 开始这一生**。动画展示使用独立随机源，不消耗模拟的种子随机序列；登记卡等待期间年龄与事件不推进。指定国家或开启系统「减少动态效果」时直接展示结果，停留后进入登记卡。`?go=1` 仍可直接进入模拟，兼容既有诊断参数。

地图为本地绘制的分布示意，不是官方泰拉疆域图。页面显示实际本地历史记录，不接入原站的在线人数、留言或追思馆服务。

新增行为检查：`node tools/verify-birth.mjs`。检查结论与后续工作见 [本次检查与首页改造记录](docs/检查与首页改造-2026-10-17.md)。

## 立刻开始玩

**方式一（推荐）**：直接双击 `index.html`。全部脚本都是普通 `<script>`，
不依赖构建、不依赖网络，`file://` 下即可运行。

**方式二**：起一个本地服务器（某些浏览器对 `file://` 限制较严时用）

```bash
node tools/serve.mjs 8814
# 然后打开 http://127.0.0.1:8814/
```

### 四种人生轨迹的差异是真实的

一次抽签会决定你的起跑线，但它不决定终点。下面这些数字来自 1000 局自动模拟：

```
平均寿命 54.5 岁
寿命分位：P10=13  P25=24  P50=59  P75=82  P90=91   最长 168

死因分布（前 8）
  心血管疾病   16.2%      多器官衰竭   14.5%
  恶性肿瘤     14.1%      意外伤害      9.5%
  脑血管疾病    7.0%      感染性疾病    5.9%
  天灾          5.8%      矿石病        4.9%
  ── 泰拉特有 ──
  天灾 5.8% · 矿石病 4.9% · 源石技艺反噬 1.7% · 纠察队处决 1.4%
  战争 1.3% · 热射病 1.3% · 野兽与荒原盗匪 1.1% · 矿坑苦役 0.8%
  饥荒 0.5% · 海嗣侵袭 0.3%

一生中感染过矿石病 15.6%（Ⅰ期 42 / Ⅱ期 71 / Ⅲ期 43）
```

**平均寿命 54 岁不是模型坏了，是这个世界的样子。** 分布是双峰的：
住在移动城市里的人活到 80 上下，住在不能移动的地方的人活到 30–45。
下面这张表就是全部原因。

| 出身阶层 | 人口占比 | 社会预期寿命 | 终生感染风险 | 天灾命中系数 |
|---|---|---|---|---|
| 移动城市核心区 | ~18% | 国家的 `le` × 1.17 | 0.8% – 2.5% | 0.22 |
| 工业与蓝领区 | ~49% | × 1.01 | 5% – 10% | 0.34 |
| 城市边缘与地下 | ~33% | × 0.89 | 12% – 24% | 0.52 |
| 荒野聚落 | 城市的补集 | **35 – 45 岁（绝对值）** | 20% – 34% | 0.95 |

**关键点**：现实病因仍然是主要死因，泰拉特有的东西以合乎设定的比例叠加在上面。
矿石病之所以可怕，不是因为它杀死了所有人（17.9% 的人一生中感染过），
而是因为它杀死的那部分人被剩下的人赶出了城。

## 核心机制

### 1. 抽签：两种口径，结果差别很大

沿用原作设计，出生地按**加权抽签**，并提供两种统计口径：

- **此刻出生的婴儿** —— 按年出生人数加权
- **此刻活着的所有人** —— 按人口加权

炎国占大陆人口的 ~38%，但因为生育率低，在「婴儿」口径下只占 ~30%；
卡兹戴尔人口不到 1%，却因为高生育率与高死亡率在婴儿口径下更常见。
这个差异本身就是一句叙事。

人口数据取自《大地巡旅》官方数值 + 社区推算（社区部分已在 `nations.js` 注明）。

### 2. 生命表：整个模拟的数学核心

`js/engine/lifetable.js` 从原作算法出发，做了两处结构性改动。

**改动一：危险率拆成两个独立项。**

```
hazard(x) = external(x) + senescence(x)

  external(x)    外部风险：贫穷、暴力、天灾、职业病、医疗可及性
                 → 用二分搜索反解，使 Σ 生存人年 = 该阶层的社会预期寿命
  senescence(x)  Gompertz-Makeham 衰老项，斜率 g 由**种族的生理极限**决定
```

原作只有一个混合项。拆开之后，「一个萨卡兹在乌萨斯能活多久」这个问题
才有两个独立的答案可以调：社会能让他活多久（external），
以及他的身体本身能撑多久（senescence）。阿戈尔的生理极限是 120–160 岁，
但如果他生在乌萨斯的荒野，社会预期寿命只有 37 岁 —— 他会在能活很久的
身体里很早就死掉。这两条曲线的差，就是「泰拉」本身。

**改动二：生理极限与社会预期寿命分离。**

```
lifeMax   种族（或王庭血脉）决定：先民 80–100，阿戈尔 120–160，
          德拉克 / 阿斯兰 120–180，龙 130–190，萨卡兹王庭 150–1500
socialLE  阶层决定（见上表）
```

两者的差距就是「这个人生错了地方」。`TL.lifeMaxOf()` 给出前者，
`TL.stratumLE()` 给出后者，`TL.playAge()` 负责把长达数百年的王庭血脉
压缩到可玩的时间轴上：

```
playAge(a)      = a <= 60 ? a : 60 + 40·ln(1 + (a-60)/40)
playAgeDeriv(a) = 40 / (40 + (a-60))
```

一个活到 800 岁的巫妖不会让你玩 8 小时 —— 但他 60 岁之后的每一年
在主观时间上也确实越来越短，这正是长生者抱怨的那件事。

### 3. 阶层：泰拉的寿命不平等是空间性的

`js/data/nations.js` 的 `TL.STRATA` 是第二个寿命维度。现实世界的寿命
不平等主要沿着收入分布，泰拉的不平等沿着**能不能移动**分布：

- 移动城市每次收到天灾预警，可以启动主引擎把整块地挪走。
  荒野聚落没有引擎，只能跑，或者不跑。
- 城市有过滤系统与稳定供水，荒野有露天水井。
- 工业废渣排到城市边缘，边缘的人喝的就是那些水。

抽签顺序：**阶层 → 国家 → 种族**（`TL.drawStratum` 先按国家的城市人口
占比决定城里/荒野，再在城市内部按核心/工业/边缘细分；家境越好越靠内）。
所以「一个炎国的核心区龙族」与「一个炎国的荒野库兰塔」是两个不同的游戏。

### 4. 四维不是加减法，是「向目标回归」

原作最精妙的一点，本作完整保留：

```js
st.hl += (hTarget - st.hl) * 0.25;   // 体质
```

`hTarget` 由年龄基准、生活习惯、慢性病、家境、矿石病分期、年度重心共同算出。
这意味着一次重病会留下**永久痕迹**，而持续调养会缓慢拉回来 —— 像真的身体。
心境与羁绊用同样的机制，各自有独立的目标函数。

### 5. 矿石病：本作的核心扩展

原作没有这一维。泰拉版把「感染者」从一个标签做成了一条真实的人生分支：

- **感染判定**：阶层区间 × 职业覆盖（源石采掘工 58–70%）× 种族亲和 ×
  技艺适应性 × 贫困 × 医疗水平 × 天灾后暴露。所有感染路径统一走
  `TL.tryInfect()`，不存在绕过校准的旁路。
- **终生概率 → 固定年风险**：设定值是「终生感染概率」，换算成**不随年龄
  变化**的年度风险。早期版本用「剩余年数」逐年重算，结果任何活得比
  `e0+6` 久的人都会在余生每年重赌一次整份终生概率 —— 一个 e0=79 却活到
  111 岁的人凭空多出 40% 感染率，把全大陆感染率推到 47%。这是本作最难查的
  一个 bug，成因与修法都写在 `oripathy.js` 的注释里。
- **分期推进**：结晶率 0→100，Ⅰ期 / Ⅱ期 / Ⅲ期；技艺越强推进越快
  （源石亲和是天赋也是诅咒），抑制治疗可减缓 ~50%
- **容忍度分级**：21 个国家各有一个 0–100 的感染者容忍度，归入 5 个档位，
  每档对应不同的 `arrest`（被纠察队抓捕的概率）与 `treatP`（能获得治疗的
  概率）。乌萨斯 8 分：感染即丧失全部人权，纠察队可就地扑杀或押送北原
  矿区为奴工（游戏里有独立的 `slave_life` 事件链）。拉特兰 26 分，
  阿戈尔 86 分。
- **两条出路**：罗德岛（正规治疗，昂贵）与整合运动
  （`TL.reunionLean()` 由被排斥的程度算出 —— 不是善恶，是被推到了哪里）

### 6. 天灾：移动城市与荒野是两套完全不同的机制

| | 移动城市 | 荒野 |
|---|---|---|
| 预警 | 每年 3–6 次 | 0–1 次 |
| 应对 | 启动主引擎偏航规避 | 只能跑 |
| 正面命中率 | 22% / 34% / 52%（按阶层） | 95% |
| 大迁徙 | 每 4–7 年一次 | 不存在 |
| 毁灭级风暴 | 无 | 每 20–30 年一次 |
| 致死 / 致残 | 天灾后清理废墟（感染风险 ×2.6） | 15% 致残、其中少数死亡 |

事件有**一生次数上限**（`max`），且上限在 `TL.fire()` 这个唯一入口处拦截 ——
只在选池时拦截是不够的：调度器里那些「强制排入」的事件（阶层天灾、
纠察队、矿坑苦役）根本不走选池，于是城市偏航能在一条命里刷二十几次，
同一句话重复到读者出戏。修好之后单局日志重复率从 40% 降到 24%。

### 7. 泰拉大事件：历史是别人的，也是你的

`js/data/timeline.js` 收录 1031–1099 年的 34 条大陆级事件（四皇会战、伦蒂尼姆事变、
大静谧、孤星计划、万国峰会……），完整设定见 [`docs/泰拉大事件年表.md`](docs/泰拉大事件年表.md)。

**出生年份是抽的，不是固定的。** 1042–1095 三段分权，所以每次抽到的时代不同 ——
你没法选择自己生在哪个时代，这本来就是这游戏的第一条规则。

事件按**感知距离**分三档播报：`亲历`（在本国）/ `邻国`（同大区）/
`远方`（一句船期新闻）。三档都有各自的文案，不是同一句话换个前缀。

```
17岁  拉特兰召开万国万教代表大会。          [万国峰会与「原初律法」启示]
17岁  叙拉古废除旧家族法典，设立独立司法官。  [沃尔西尼「新城」落成与血色家族解体]
```

**出生之前发生的事也会讲。** 一个 1050 年生在伊比利亚的人，大静谧（1038）不是新闻，
而是他整个国家的性格：国境已经封了十二年，灯塔还没修好，审判庭早就在那里了。
所以开局会补一句「你出生前 N 年，……」—— 让你知道自己继承了一个什么样的世界。

**死亡永远是条件性的。** 只有你确实在那座城里，才可能死于那座城的事：

```js
{ when: S => S.city.indexOf('切尔诺伯格') >= 0,
  die: 0.10, dieCause: 'cat', move: '流民', ... }
```

一个生在汐斯塔的人不会死于伦蒂尼姆战役。

**最后一条，也是最要紧的一条：生命表是慢变量，事件是快变量。**
事件绝不重算 `q(x)`。四皇会战不改变维多利亚人的生理寿命，
它只改变那几年谁死了、谁破产了、谁搬走了、谁把袖子拉得更低了一点。
把事件做进生命表，模型就再也解释不清自己了。

### 8. 平衡是如何校准的

数值不是拍脑袋定的，每一步都有对应的诊断工具：

| 工具 | 用途 |
|---|---|
| `tools/headless.mjs` | 批量跑人生，输出寿命分位、死因分布、职业分布、感染率 |
| `tools/verify.mjs` | **结构自检**：DOM id 是否都存在、`TL.t()` 的中英两表是否齐全、事件池里有没有写错的 id、事件与抉择的结构是否完整 |
| `tools/diag-mort.mjs` | 拆解死亡率乘数，找出是哪一项在压低寿命 |
| `tools/diag-hl.mjs` | 对比各年龄段的 hl 与同龄基准，检查体质模型是否失衡 |
| `tools/diag-nation.mjs` | 逐国对比「模拟寿命 vs 设定寿命」「模拟感染率 vs 设定感染率」 |
| `tools/diag-ori2.mjs` | 把感染拆成「年度独立判定 / 各事件的 k 倍放大」分别统计 |
| `tools/diag-dup2.mjs` | 单局内日志重复率（衡量叙事是否会读起来像卡带） |
| `tools/gen-baseline.mjs` | 生成 `js/data/baseline.js`：每国 × 性别的模拟基线寿命 |

`node tools/verify.mjs` 值得单独说一句。界面重排之后最容易出的一类 bug 是 id 写错：
`$('statBody')` 打成 `$('statbody')` 返回 `null`，那一段渲染整个不执行 ——
**它不会报错，只会让某个面板永远空着**，而你可能几十局都碰不到那条路径。
这个脚本把 render/main 里所有 `$('…')` 抽出来对照 `index.html` 检查一遍，
顺便验证 `TL.t()` 的键在中英两表里都存在。它抓到过一个真 bug：
`S.job = 'slave'`（矿坑苦役）没有登记在 `TL.NONWORK_LABEL` 里，
界面上会直接印出英文单词 `slave`。

几个典型的校准案例（都记录在代码注释里）：

- **慢性病不能进事件池**。早期把 `illness` 放进常规池，结果 200 人里 120 人得了
  5 种以上慢性病，体质被压到 50 以下（应约 84）。改成独立的年发病风险 + 封顶 3 种。
- **`off` 常数必须吸收随机损耗**。`deathProb` 里 `expHealth(a) - off - hl` 的 `off`
  是「随机不幸消耗的健康余量」。因为年度回归只有 25%，hl 的均衡点天然低于
  `expHealth` 约 4×年损耗。把 `off` 设成这个均衡差，平均人才会得到 `m = 1`。
- **阶层区间的加权平均值必须回到设定**。荒野的终生感染区间若照抄
  「30–50%」，再乘上荒野人口占比，全大陆感染率会到 47% —— 那等于说半个
  泰拉都是感染者，与基本设定矛盾。现在的区间是按「加权后落在 15–20%」
  反推的，理由写在 `nations.js` 的 `TL.STRATA` 注释里。

### 9. 报告里的对比为什么是「模拟 vs 模拟」

国家设定的 `le` 现在应当读作**移动城市的社会预期寿命**：荒野的绝对值区间
（35–45 岁）与它无关，而一个荒野人口占多数的国家，其真实国民平均寿命
必然远低于 `le`（萨米：设定 72，模拟 32–38）。报告因此用 `TL.BASELINE_LE`
（同为该国该性别的 320 局模拟人生）作基准，并同时给出统计寿命供参考。

## 界面：为什么按这个版式排

原作《80億分之1》的画面结构是本作界面的直接来源。三栏、浅底深字、
顶栏一排离散倍速按钮，都是照着重做的：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 泰拉人生  14岁 │ 14年 · 姓名 · 在学 · 1年≈48.4秒 │ 暂停 1× 2× 4× 8× 12× 16× │
│                │ 炎国 · 工业与蓝领区              │ 快转到下一个抉择 » 自动 …│
├──────────────┬──────────────────────────────┬────────────────────────────┤
│ 身份记录·YAN │ [像素场景 · 160×64]          │ 家人与生活                 │
│  头像+姓名   │  云中 · 炎国 · 工业区 · 少年  │  母亲 42岁 · 厨师          │
│  属性表      │                              │  兄弟姐妹 16岁 · 学生      │
│  MRZ 条码    │ 今年的重心                   │ 在同一秒出生的人们         │
│ 状态 0-100   │  帮家里干活 羁绊↑ 学识↓ 100% │  还活着 585 / 600 · 97.5%  │
│  健康 91 ▓▓▓ │  玩耍 / 锻炼 / 爱好 …        │ 人生地图（一格一年）       │

```

几个刻意的选择：

- **像素场景是程序化生成的**（`js/ui/pixelart.js`）。160×64 内部画布、
  只用整数 `fillRect`、种子取自姓名哈希，所以同一个人每次打开长得一样。
  21 个国家各有独立调色与地标（炎国的塔、乌萨斯的烟囱、萨尔贡的穹顶、
  阿戈尔的水下珊瑚墙、杜林的地下机械），阶层与人生阶段再叠一层修饰
  （核心区灯火更密，荒野结构最少）。
  调色在载入时统一做一次「日光提亮」：原稿是按夜戏定的，
  放进奶油色界面里像一块没开灯的屏幕。
- **人生地图一格一年，越深越幸福**，外框标出预期寿命所在的那一格。
- **存活曲线是你的同期群**：出生时用同一张生命表反解出 600 个虚拟同伴的
  死亡年龄，所以国家、性别、种族、阶层任何一项变了，这条曲线也跟着变。
- **速度是离散的七档**（暂停 / 1× / 2× / 4× / 8× / 12× / 16×），不是滑块 ——
  因为原作就是这样，而且离散档位让你能明确地"停在某一年看"。

### 地区维度

原作是台湾团队做的，界面是繁体中文，净资产一律「以台灣物價計」。
本作不把任何一个地区写成固定维度，而是：

1. 读浏览器时区 + 语言判定地区；
2. 语言以 `zh` 开头 → 中国，其余 → 美国；
3. 允许 URL `?region=` 或设置面板手动覆盖（写进 localStorage）。

地区只影响**界面语言与货币口径**（元 / $ / ¥ / €，以及那句「以…物价计」），
不影响寿命、死亡率、矿石病、天灾等任何世界模型。目前提供中国、
美国、日本、韩国、欧洲五个地区。

英文界面的覆盖范围与**边界**（有意为之，不是没做完）：

| 已翻译 | 保持中文 |
|---|---|
| 全部界面文案与按钮、工具浮层 | **事件与抉择的叙事文本** —— 那是这个游戏的语气，翻过去就不是它了 |
| 21 国国名、26 种族、11 支王庭 | 人名、城市名等专有名词 |
| 4 个出身阶层（含短名） | |
| 6 个人生阶段、4 个矿石病分期 | |
| 60+ 职业名、干员五阶与八分支 | |
| 22 个年度重心的名称与效果摘要 | |
| 四维的定性描述（壮健 / Robust 等）、学历档位、技艺等级 | |

取值统一走三个 helper：`TL.nameOf(rec)` / `TL.shortOf(rec)` / `TL.descOf(rec)`，
它们在 `TL.lang !== 'en'` 或该记录没有英文字段时回落中文，
传入 `null` 返回空串而不会抛异常。

## URL 参数（调试 / 分享特定一局）

```
?go=1                 跳过开局界面直接出生
?auto=1               自动模式
?ff=40                瞬间推进到 40 岁（用于看某个阶段）
?hold=1               配合 ff：停在第一个未决抉择上（截图 / 验证弹层）
?speed=4              初始倍速（1 2 4 8 12 16）
?region=US            地区：CN | US | JP | KR | EU
?by=1070              强制出生年份（泰拉历）。默认从 1042–1095 之间抽
?mode=pop             抽签口径：birth | pop
?nation=YAN&race=sarkaz&sex=F&pace=short&seed=abc123
```

例：
`http://127.0.0.1:8814/?go=1&auto=1&speed=8&nation=KDZ&race=sarkaz&seed=demo`

同 `seed` 必然复现同一局。想直接看 1099 年那几件事：`?go=1&by=1082&ff=17&nation=VIC`。

## 关于设定与数据

- 世界观、国家、种族、组织、术语均来自《明日方舟》（Hypergryph / Studio Montagne）。
  本作是非商业同人作品。
- 各国人口优先采用《大地巡旅》官方数值（炎国 3 亿、萨尔贡 1 亿、乌萨斯 8000 万、
  维多利亚 4000 万、莱塔尼亚 3200 万、雷姆必拓 2800 万、哥伦比亚/玻利瓦尔各 1600 万、
  拉特兰 600 万、汐斯塔 80 万），其余为社区推算，已在数据文件中逐条标注。
- 寿命、婴儿死亡率、感染率、天灾频率等**没有官方数值**，是为了让模拟成立而做的
  叙事化推演。它们的目标不是「准确还原官方设定」，而是让不同国家的人生
  在统计上呈现可信的差异。
- 模拟逻辑移植自 1in8billion 的人生模拟框架。原作的实时播放节奏、
  加权抽签、生命表反解、四维回归、事件队列等设计均予保留。

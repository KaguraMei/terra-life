# 泰拉模型：与原作《80億分之1》的差异

本文只记录**改动**与**改动的原因**。原作本身的逻辑（时间推进、事件队列、
四维回归、生命表反解、加权抽签）见 [`原始逻辑-1in8billion.md`](原始逻辑-1in8billion.md)。

一句话总结：原作模拟的是「一个人生在哪个国家」，本作模拟的是
「一个人生在泰拉的哪个位置」—— 而泰拉最重要的事实是，
有些地方可以移动，有些地方不能。

---

## 1. 生命表：一项危险率拆成两项

**原作**

```
q(x) = 1 - exp(-h(x))
h(x) = A + B·e^{g·x}          ← 外部风险与衰老混在一个 A 里
对 B 二分搜索，使 Σ 生存人年 = e0
```

**本作**

```
h(x) = external(x) + senescence(x)

  external(x)    贫穷、暴力、天灾、职业病、医疗可及性
                 → 二分反解，使 Σ 生存人年 = 该阶层的 socialLE
  senescence(x)  Gompertz-Makeham，斜率 g 由种族的生理极限 lifeMax 决定
```

**为什么改。** 原作里「这个国家的人活得短」与「这个人的身体撑不住」
是同一件事。泰拉不是：阿戈尔的生理极限是 120–160 岁，但如果他生在
乌萨斯的荒野，社会预期寿命只有 37 岁。他会在一具能活很久的身体里
很早就死掉。不把两项拆开，就没法表达这件事 —— 而这件事就是泰拉。

拆分之后 `TL.lifeTable()` 的签名变成：

```js
TL.lifeTable(nation, sex, raceId, courtId, stratumId)
```

## 2. 寿命：生理极限与社会预期寿命分离

| | 由什么决定 | 取值范围 | 取法 |
|---|---|---|---|
| `lifeMax`（生理极限） | 种族 / 萨卡兹王庭血脉 | 先民 80–100，阿戈尔 120–160，德拉克 / 阿斯兰 120–180，龙 130–190，王庭 150–1500 | `TL.lifeMaxOf(raceId, courtId)` |
| `socialLE`（社会预期寿命） | 出身阶层 | 城市核心区 ≈ 国家 `le` × 1.17 … 荒野 35–45（绝对值） | `TL.stratumLE(nationId, stratumId)` |

**城市内部的系数是归一化的。** `core / industrial / fringe` 的 `leK`
（1.00 / 0.86 / 0.76）只是「形状」，最后要按城市人口配比归一化，
使**城市加权平均正好等于国家的 `le`**。早期直接用 `n.le * leK`，
结果全国平均寿命被整体拉高，国家的 `le` 失去意义。

**荒野用绝对值而非系数。** 不能移动的地方不可能有 70 岁的社会预期寿命；
区间内的位置由国家发展水平（`ppp`）决定。

**副作用需要说清楚：** 一个荒野人口占多数的国家，它的 `n.le` 不再等于
国民平均寿命。萨米设定 72，模拟 32–38。这不是 bug —— 是 `le` 的定义
变成了「这个国家的移动城市里能活多久」。报告因此用同为模拟的
`TL.BASELINE_LE` 作基准（见 README 第 8 节）。

### 时间压缩

王庭血脉能活到 1500 岁。线性播放意味着 15 小时。所以引入主观时间轴：

```
playAge(a)      = a <= 60 ? a : 60 + 40·ln(1 + (a-60)/40)
playAgeDeriv(a) = 40 / (40 + (a-60))
```

`playAgeDeriv` 用于把「每模拟年的真实秒数」按年龄缩放，所以长生者
60 岁之后的每一年在主观时间上也确实越来越短。这不是为了省事，
这正好是长生者抱怨的那件事。

## 3. 阶层：泰拉的寿命不平等是空间性的

**原作**没有阶层，国家的 `le` 就是所有人的 `le`。

**本作**新增 `TL.STRATA`（`js/data/nations.js`）：

| id | 名称 | leK / leAbs | imK / u5K | 终生感染 | 天灾命中 | urban |
|---|---|---|---|---|---|---|
| `core` | 移动城市核心区 | 1.00 | 1.0 / 1.0 | 0.8–2.5% | 0.22 | ✓ |
| `industrial` | 工业与蓝领区 | 0.86 | 1.4 / 1.5 | 5–10% | 0.34 | ✓ |
| `fringe` | 城市边缘与地下 | 0.76 | 2.0 / 2.1 | 12–24% | 0.52 | ✓ |
| `wild` | 荒野聚落 | 35–45（绝对） | 2.7 / 2.9 | 20–34% | 0.95 | ✗ |

### 级联抽签：阶层 → 国家 → 种族

`TL.drawStratum(nationId, q, rnd)` 先按国家的城市人口占比
（`TL.cityShare()`，由 `urb` 与 `ppp` 推出，夹在 0.34–0.92）决定城里/荒野，
再在城市内部按 `core / industrial / fringe` 的配比细分；家境分位 `q` 越高
越靠内。所以「炎国核心区的龙族」与「炎国荒野的库兰塔」是两个不同的游戏。

### 连带效应

阶层同时改了四件事，它们必须一起改，只改一件会让模型自相矛盾：

1. 生命表的外部风险（`socialLE`）
2. 婴幼儿死亡率（`imK` / `u5K`）
3. 矿石病的终生感染区间（`ori`）
4. 天灾的命中系数与排程方式（`catHit` / `urban`）

## 4. 天灾：移动城市与荒野是两套机制

**原作**只有一条 `cat_warning`，按国家的 `cat` 频率随机出现。

**本作**按 `stratum.urban` 分成两条完全不同的轨道：

| | 移动城市 | 荒野 |
|---|---|---|
| 预警 | 每年 3–6 次 | 0–1 次 |
| 应对方式 | 启动主引擎偏航规避（`cat_city`） | 只能跑（`cat_wild`） |
| 正面命中 | `catHit` × 0.32 | 15% 致残 / 其中少数死亡 |
| 大迁徙 | 每 4–7 年一次（`cat_migrate`） | 不存在 |
| 毁灭级 | 无 | 每 20–30 年一次（`cat_mega`），12% 死亡 |
| 灾后 | 清理废墟 → 感染风险 ×2.6 | 聚落消失、沦为流民 |

排程是**强制入队**而非加入选池，因为低频重大事件不能被随机挑选跳过。
这带来一个新问题，见第 6 节。

## 5. 矿石病：设定值是终生概率，不是年概率

**原作没有这一维。**

本作的核心校准原则：`TL.STRATA[x].ori`、`JOB_ORI`、`NATION_ORI`
给出的全都是**终生感染概率**，需要换算成年度风险。

### 换算必须是固定的，不能逐年重算

```
✗ 早期写法：remain = endAge - age；p = 1-(1-L)^(1/remain)
✓ 现在写法：p = 1-(1-L)^(1/(min(e0+6,90) - 6))，此后不随年龄变化
```

**为什么。** 早先的写法在「恰好活满预期寿命」的前提下数学上是对的，
但只要有人活得比 `endAge` 久，`remain` 就会被 `Math.max(1, …)` 夹到 1，
年风险直接跳成整份终生概率。一个 `e0 = 79` 却活到 111 岁的人，
后 26 年每年都在赌 2% —— 累积感染率凭空多出 40%，
把全大陆终生感染率推到 47%（设定目标是 15–20%）。

**这是本作最难查的一个 bug**，因为它只在长寿者身上显现，
在短样本里看起来完全正常。诊断工具是 `tools/diag-ori2.mjs`：
它把「设定终生概率」与「实际年风险累加」并排打印，
两者相差十倍时一眼就能看出来。

### 阶层区间也是反推的

原稿给的是「荒野流民 30–50%、城市边缘 20–35%」。但那几个数字是
「一辈子没离开过这里的人」的条件概率，不是人口加权后的患病率。
直接照抄，再乘上约 1/3 的荒野人口占比，全大陆终生感染率会到 47% ——
那等于说半个泰拉都是感染者，与「感染者是被迫害的少数群体」这一
基本设定直接矛盾。所以现在的区间是按「加权后全大陆落在 15–20%」
反推的。理由写在 `nations.js` 的 `TL.STRATA` 注释里。

### 容忍度分级

21 个国家各有一个 0–100 的感染者容忍度（`TL.TOLERANCE`），
归入 5 个档位（`TL.TOL_INFO`），每档给出三个数：

| 档位 | 分数 | `lifeK` 寿命系数 | `arrest` 被抓概率 | `treatP` 获得治疗 |
|---|---|---|---|---|
| 极度迫害与苦役 | 0–15 | 0.20 | 0.42 | 0.02 |
| 体制化隔离与排斥 | 15–35 | 0.40 | 0.20 | 0.10 |
| 资本盘剥与工具化 | 35–55 | 0.62 | 0.08 | 0.26 |
| 行政收容与有限庇护 | 55–75 | 0.85 | 0.02 | 0.45 |
| 平权 / 感染者自治 | 75–100 | 1.00 | 0.00 | 0.60 |

乌萨斯 8 分：感染即丧失全部人权，纠察队可就地扑杀或押送北原矿区为奴工 ——
游戏里有独立的 `ori_arrest` / `slave_life` 事件链。
拉特兰 26 分，阿戈尔 86 分。

## 6. 事件次数上限必须拦在唯一入口

**原作**用 `w / cd / max` 三张表控制事件频率。

**本作**保留，但把 `max` 的检查从「选池时」挪到了 `TL.fire()`：

```js
// year.js · TL.fire()
if (ev.max != null && (S.evCount[e.id] || 0) >= ev.max) return;
```

**为什么。** 只在 `pickFrom` 里拦是不够的：`scheduleEvents` 里那些
「强制排入」的事件（阶层天灾、纠察队、矿坑苦役）根本不走选池。
结果是城市偏航能在一条命里刷二十几次，同一句话重复到读者出戏。
修好之后单局日志重复率从 40% 降到 24%。

## 7. 地区维度：删掉台湾，改成跟随用户

**原作**是台湾团队做的，界面繁体中文，净资产一律「以台灣物價計」。

**本作**不把任何一个地区写成固定维度：

1. 读浏览器时区（`Intl.DateTimeFormat().resolvedOptions().timeZone`）+ 语言；
2. 语言以 `zh` 开头 → 中国大陆，其余 → 美国（兜底）；
3. URL `?region=` 或设置面板可手动覆盖，写进 `localStorage`。

地区表 `TL.LOCALES` 有中国大陆、美国、日本、韩国、欧洲五条，
每条给出语言、货币符号、购买力倍数与那句口径说明。

**边界说清楚：** 地区只影响界面语言与货币口径，
**不影响**寿命、死亡率、矿石病、天灾等任何世界模型。
地区是「你怎么看这些数字」的镜头，不是「世界怎么运转」的参数。
界面文案有简中与英文两套；事件与抉择的叙事文本只有中文。

## 8. 界面：版式来自原作截图，不是自由发挥

原作画面结构：顶栏（品牌 · 大号年龄 · 年份/姓名/秒数 · 一排离散倍速 · 工具），
三栏（身份记录 / 场景与记录 / 家人与地图），浅底深字。

本作照此重做，替换掉早期的深色卡片堆叠。三处因题材而必须新增：

1. **像素场景**（`js/ui/pixelart.js`）—— 原作是照片风的静物，
   泰拉没有照片，改用 160×64 的程序化像素画：21 国独立调色与地标，
   阶层与人生阶段叠修饰，种子取自姓名哈希（同一个人每次打开长得一样）。
   调色在载入时统一做一次「日光提亮」：原稿按夜戏定的，
   放进奶油色界面里像一块没开灯的屏幕。
2. **存活曲线 + 在同一秒出生的人们** —— 出生时用同一张生命表反解出
   600 个虚拟同伴的死亡年龄（`js/engine/cohort.js`）。
   国家、性别、种族、阶层任何一项变了，这条曲线也跟着变。
3. **人生地图** —— 一格一年，越深越幸福，外框标出预期寿命那一格。

## 10. 三处数据勘误

写完自检脚本（`tools/verify.mjs`）之后顺着查出来的，记在这里以免再犯。

### 十王庭：一个臆造支系

原来的名单里有「死魂灵 / Soul Reaper」，但官方十王庭里没有这一支 ——
它是本作早期凭空造的。同时官方名单里的**炎魔（Diablo）**缺席。
现在已把 `soulreaper` 换成 `diablo`，十支与 wiki 一致：
血魔 / 温迪戈 / 女妖 / 石翼魔 / 食腐者 / 变形者（Damazti）/ 炎魔 /
巫妖 / 独眼巨人 / 笞心魔（Djall）。

### 种族 id 与名字对不上

`id: 'zalak'` 配 `name: '萨弗拉'` —— Zalak 是札拉克（啮齿类），
萨弗拉是 Savra（鳞与尾，冷血）。`desc` 写的是后者，说明 id 写错了。
已把 id 统一改成 `savra`，并同步 `nations.js` 的 8 处种族池与 `render.js` 的兽耳判定。
同理 `id: 'tiacauh'` 配 `name: '提卡兹'`：提卡兹是 Teekaz（古代萨卡兹），
id 与 desc（阿卡胡拉）都指向提亚卡乌，已把名字改回 `提亚卡乌`。

### `slave` 不在职业表里

`ori_arrest` 会把 `S.job` 设成 `'slave'`（矿坑苦役），但这个值没有登记在
`TL.NONWORK` / `TL.NONWORK_LABEL` 里，后果有三层：

1. 界面上会直接印出英文单词 `slave`（`jobLabel` 找不到就回退成原字符串）；
2. `TL.isWorking('slave')` 返回 `true`，于是 `year.js` 每年做
   `if (TL.isWorking(S)) S.flags.lastJob = S.job` —— **出矿之后永远回不到原来的职业**；
3. 更根本的是，当时**没有任何出矿的路径**。一次 `ori_arrest` 判定等于无期徒刑，
   玩家从此没有任何可做的事。泰拉确实有这种结局，但它应该是一次坏运气，
   而不是一条没有出口的走廊。

现在：`slave` 归入非工作状态（修掉 1 和 2），并新增 `slave_out` 事件 ——
赎人 / 特赦 / 逃 / 病退四种，每年约 12% 的机会。1500 局实测：
1.5% 的人生进过矿坑，其中 48% 出来了，服刑年数中位数 2 年。

### 收入分位在高端饱和

`pct` 的锚点是 `log(income/0.35)/log(8)`，也就是月收入 ≥ 2.8 一律算 100%。
实测月收入能到 9 以上，于是 **17% 的人全部钉在 100%** ——
「大陆收入分位 100%」既可能是一个普通干员，也可能是整个大陆最富的人。
现在锚点取自实测分布（低端 0.05、高端 15），中位数落在 36%，
P90 是 75%，再无饱和。

## 11. 泰拉大事件：第三个时间维度

**原作**没有历史。每一年都是同一个世界，只是你在变老。

**本作**加了一条 1031–1099 的大陆年表（34 条，`js/data/timeline.js`，
完整设定见 [`泰拉大事件年表.md`](泰拉大事件年表.md)）。

### 日历换成泰拉历

```js
S.bornYear = TL.drawBirthYear(TL.rnd);   // 1042–1095 三段分权
S.year = S.bornYear + S.age;             // 年表按 S.year 对齐
```

出生年份是抽的，不是固定的。你没法选择自己生在哪个时代。

### 三档感知

| 档 | 条件 | 播报 |
|---|---|---|
| `here` | 在本国 | 亲历，第一人称 |
| `near` | 同大区 | 只听说，转述 |
| `far` | 其他 | 一句船期新闻 |

三档各有独立文案，不是同一句话加前缀。

### 出生之前的事也要讲

一个 1050 年生在伊比利亚的人，大静谧（1038）不是新闻，而是他整个国家的性格。
持续型修正本来就跨年生效（`TL.tlMods` 按 `year - ev.year < dur` 判定），
`TL.timelineBackstory()` 补的是那句话：**让你知道自己继承了一个什么样的世界。**

### 死亡是条件性的

```js
{ when: S => S.city.indexOf('切尔诺伯格') >= 0,
  die: 0.10, dieCause: 'cat', move: '流民' }
```

一个生在汐斯塔的人不会死于伦蒂尼姆战役。事件的致死率只对**确实在场**的人生效。

### 最重要的一条：生命表是慢变量，事件是快变量

事件绝不写进 `q(x)`。接入点只有四处，全部是「乘当年」：

| 接入点 | 读什么 |
|---|---|
| `TL.deathProb` | `tl.mort` 与 `tl.war` |
| `TL.causeWeights` | `tl.ori` / `tl.cat` / `tl.war` / `tolInfo(nation, year)` |
| `TL.oriLifetimeP` | `tl.ori` |
| `TL.tolOf(id, year)` | `tl.tol` |

四皇会战不改变维多利亚人的生理寿命，它只改变那几年谁死了、谁破产了、谁搬走了。
把事件做进生命表，模型就再也解释不清自己了。

### 实测

`node tools/diag-timeline.mjs 800`：

```
出生年份：P10=1050  P50=1073  P90=1091
平均每局亲历到的大事件：16.0 条
一条都没碰到的局：3.0%
碰到 5 条以上的局：89.5%
```

`tools/verify.mjs` 会把年表当外键来查 —— `fx` 与 `scope.nations` 里任何一个
国家 id 拼错，那一条就永远不会对任何人生效，而且**不会报错**。

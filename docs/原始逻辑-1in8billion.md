# 原始逻辑提取：80億分之1 / 1 in 8 Billion

本文记录从 `https://1in8b.life/zh/` 与 `https://1in8billion.app/zh-cn/faq/`
提取到的游戏内核，以及它如何被移植到泰拉版。

> **本文只描述原作。** 泰拉版对这套内核做了哪些结构性改动、为什么改，
> 见 [`泰拉模型-与原作的差异.md`](泰拉模型-与原作的差异.md)。
> 两者的分工是：本文回答「原作是怎么算的」，那一篇回答「我们为什么不算得一样」。

---

## 0. 抓取方式

页面把**整套游戏逻辑内联在一个 2.9 MB 的 `<script>` 里**（无外链 JS、
无 source map），所以可以直接取出分析：

```powershell
curl.exe -s -o home.html "https://1in8b.life/zh/"
# 提取第二个（也是最大的）inline script → 约 4 MB 的可读 JS
```

> 注：原站域名在国内网络下解析到 `198.18.x.x`（Clash/Surge 类代理的
> fake-IP 段），需要走系统代理才能访问。
> FAQ 页（`1in8billion.app/zh-cn/faq/`）是纯静态说明页，用于确认设计意图。

代码未混淆，只有极少量压缩，因此逻辑完全可读。共 **1320 个函数**。

## 1. 架构总览

```
S                     全局状态对象（一个人的一生）
S.t ∈ [0,1]           年内进度
S.yearSec             走完一年需要的真实秒数
S.queue               年内事件队列，按 .at 排序
S.focus / S.fT        年度重心与各重心累计投入时间
S.pending             待玩家抉择（非空时 tick 直接 return，时间停住）

tick(dt)   ── 推进 S.t，触发队列中到期事件，t≥1 时调用 endYear()
  └ fire(e) ── 按 type 派发：ev 剧情 / ms 里程碑 / ad 收养 / hist 时代 / dec 抉择
endYear()  ── 重心结算 → 健康回归 → 社交回归 → 经济 → 死亡判定 → 排下一年事件
die()      ── 死亡叙事 + 生成人生报告
```

**时间模型**（值得单独说）：`S.yearSec = 播放分钟数 × 60 / 该人的预期寿命`。
所以预期活 60 岁的人与活 85 岁的人，同样的 1 小时里前者每年分到的时间更多 ——
「约 30/60/90 分钟」指的是**走到预期寿命**的播放节奏，不是死亡年龄。
本作完整保留了这个设计。

## 2. 数据结构

### 2.1 国家（`COUNTRIES`，172 个）

每个国家约 30 个字段，例如：

```js
{ id:"AFG", ko:"아프가니스탄", p:"sa", nm:"ps", rel:"M100",
  sp:"cricket,football", b:1469029, pop:41455, le:66.0, gap:6.0,
  u5:54.9, im:49.9, ppp:1984, gi:0.3, tfr:4.84, mmr:620, urb:25,
  agr:52, hiv:0.05, hom:4.0, road:15, mal:0.05, net:16, ter:11,
  eys:10.8, sm:40, sf:7, oop:77, cm:28, wh:1.72, cs:null,
  war:0.3, mig:"IRN,PAK,DEU", haz:"QD" }
```

| 字段 | 含义 | 泰拉对应 |
|---|---|---|
| `b` / `pop` | 年出生数 / 人口 | 直接对应（抽签权重的两种口径） |
| `le` / `gap` | 预期寿命 / 性别差 | 直接对应 |
| `im` / `u5` | 婴儿 / 五岁以下死亡率 | 直接对应（生命表输入） |
| `ppp` | 人均产出 | 直接对应（收入与死亡率的贫富梯度） |
| `gi` | 基尼系数 | 直接对应（`drawWealth` 的分布形状） |
| `urb` | 城市化 | 直接对应 |
| `edu` / `ter` | 期望受教育年 / 高等教育率 | 直接对应（就学判定） |
| `hiv` | 艾滋病感染率 | → **矿石病感染率 `ori`** |
| `war` | 战争强度 | 直接对应 |
| `hom` / `road` | 谋杀 / 交通死亡率 | 直接对应 |
| `p` | 区域代号 | `reg`，决定死因基线 `CT` 与 `MORT_G` |
| `nm` / `rel` | 姓名文化圈 / 宗教构成 | → 种族构成 |

### 2.2 四维状态

内部键名是缩写，UI 上显示为：

| 内部键 | 显示 | 泰拉版 |
|---|---|---|
| `hl` | 健康 | 体质 |
| `h` | 幸福 | 心境 |
| `sm` | 知识 | 学识 |
| `so` | 人际关系 | 羁绊 |

初值：`ST_DEF = { hl: 60, h: 55, sm: 40, so: 55 }`。

### 2.3 职业（`JOBS`）

```js
farm: { n:L`소농 (자급 농사)`, s:'agr', e:0, lo:0.03, hi:0.32, u:-1 }
miner:{ n:L`광부`, s:'ind', e:0, lo:0.25, hi:0.62, u:0,
        risk:{inj:3, copd:1.5}, male:3 }
```

`s` 部门 / `e` 学历门槛 / `lo,hi` 收入区间 /
`u` 城乡倾向 / `risk` 职业性死因倍率 / `male`·`fem` 性别倾向 / `only` 地域限定。

### 2.4 年度重心（`FOCUS`，15 项）

```js
study: { n:L`공부`, d:L`지식↑ 행복↓`, e:{ sm:5, h:-1, so:-1 } }
work:  { n:L`일에 몰두`, d:L`소득↑ 건강·관계↓`, e:{ hl:-3, h:-2, so:-2 } }
```

`e` 是四维增量。年末按 `S.fT` 里各重心占用的时间比例加权结算。

### 2.5 抉择对象

```js
// scheduleEvents 里排入 { type:'dec', id, at }
// fire() 遇到 type==='dec' 调用 openDecision(id)
// openDecision 过滤 o.c() 不成立的选项，写入 S.pending，并置 S.paused = true
// choose(index) 应用 o.eff、执行 o.run()、清空 pending
```

## 3. 核心算法

### 3.1 生命表 `lifeTable(c, sex)`

本作完整移植（`js/engine/lifetable.js`）：

```js
e0 = sex==='F' ? c.le + c.gap*0.49 : c.le - c.gap*0.51
k  = sex==='F' ? 0.92 : 1.08
q0 = min(0.25, c.im/1000 * k)
u5 = min(0.35, max(q0+0.0005, c.u5/1000 * k))
H  = -ln((1-u5)/(1-q0))
qc = [0.4, 0.27, 0.19, 0.14].map(w => 1 - exp(-H*w))       // 1-4 岁
A  = 0.00025 + 0.000028*c.u5
g  = clamp(0.112 - 0.00016*c.u5, 0.085, 0.112)             // Gompertz 斜率
q514 = 1 - (1 - min(0.2, R514[id]*c.u5/1000*k))^0.1

build(B):
  q[0]=q0; q[1..4]=qc; q[110]=1
  q[x] = x<15 ? q514 : min(1, 1-exp(-max(A + B*exp(g*(x+0.5)), OLDEST(x,sex))))
  e = Σ (x===0 ? l - 0.85d : l - 0.5d)

对 B 在 [ln 1e-8, ln 5e-2] 上二分 50 次，使 e 匹配 e0
```

### 3.2 死亡率 `deathProb()` — 本作的灵魂

```js
q = lt.q[age]
m = 1
m *= max(0.5, exp((expHealth(a) - off - S.st.hl) * (a<5 ? 0.02 : 0.03)))
m *= exp(-g*(qe-3)) / norm                      // 贫富梯度（g = MORT_G[region]）
m *= smk / (1 + 0.7*sp)                         // 吸烟（按国家流行率归一）
m *= 1.5 若酗酒 · 2 若吸毒
m *= 1.3^未治疗慢性病数
m *= 1.15 若难民 · 1.3 若服刑 · 战时服役加成
m *= tiesK(a) · ethMortK() · ddMortK() · suicMortK()
m *= calOf(c.id) · eraMort(c, a)
return 1 - (1-q)^clamp(m, 0.25, 9)
```

`expHealth(a)` 给出同龄基准体质：`72 / 80 / 90 / 90-(a-30)*0.6 / max(15, 72-(a-60)*0.95)`。

**移植时踩过的坑**：`off` 不是随手取的 6，而是「随机不幸消耗的健康余量」。
年度回归只有 25%，所以 `hl` 的均衡点天然低于 `expHealth` 约 `4 × 年损耗`。
把 `off` 设成这个均衡差，平均人才会得到 `m = 1`；否则整个社会凭空多背一层惩罚，
平均寿命会从 72 掉到 54（这是在泰拉版里实测到的）。

### 3.3 四维回归（`endYear`）

```js
// 体质
st.hl += (hTarget - st.hl) * 0.25
// hTarget = expHealth(a+1) + 各种生活方式修正 - 慢性病 - 债务 - 难民…
// 社交
t = soTarget - SO_K * clamp((a-14)/6, 0, 1)
st.so += (t - st.so) * (st.so > t ? 0.12 + (SO_UP-0.12)*ak : 0.12)
```

这个「向目标回归」而不是「加减」的设计，让一次重病留下永久痕迹、
持续调养缓慢拉回 —— 像真的身体。

### 3.4 死因权重 `causeWeights(c, a, sex, personal)`

查区域基线 `CT[region][band]`（band 按 0/1-4/5-14/15-49/50-69/70+ 分六段），
再按国家特异指标调节：

```js
w.hiv  *= (c.hiv / REF.hiv[P])^0.8
w.mal  *= c.mal / REF.mal.ssa
w.hom  *= (c.war>0 ? min(c.hom, 2*REF.hom[P]) : c.hom) / REF.hom[P]
w.road *= c.road / REF.road[P]
w.war  += (15≤a<50 ? (sex==='M'?8:3) : 2) * c.war
// 个人层：吸烟、慢性病、吸毒、职业风险、酗酒、服刑、HIV、战时、贫困
```

最后 `wpick()` 加权抽取。泰拉版在此基础上加入了矿石病、天灾、
源石技艺反噬、海嗣侵袭、失温、热射病等死因。

### 3.5 抽签

```js
chooseCountry(mode) = wpick({ [id]: mode==='pop' ? c.pop : c.b })
```

两种口径的概率差异是刻意保留的：炎国人口占 ~38%，出生只占 ~30%。

## 4. 移植映射表

| 原作 | 泰拉版 | 说明 |
|---|---|---|
| `COUNTRIES` × 172 | `NATIONS` × 21 | 官方人口 + 社区推算 |
| `CT[region][band]` | 重写为 8 个泰拉区域 × 6 个龄段 | 加入 `ori/cat/art/sea/cold/heat` |
| `hiv` / `hivMult` | `ori` / `oriMortK` | 从单一乘数扩展为完整的感染→分期→歧视系统 |
| `ethDraw` / 种姓 | `drawRace` / 萨卡兹十王庭 | 加入社会地位与歧视系数 |
| `JOBS` | 60+ 职业 + 罗德岛八大干员分支 | 加入技艺门槛与感染风险 |
| `FOCUS`（15） | 18 项，含源石技艺修习 / 矿石病治疗 / 隐藏身份 / 感染者互助 | |
| `EVMAP` | 70+ 事件 | |
| 抉择 | 30+ 抉择 | 感染者身份会改写选项形状 |
| `lifeTable` / `deathProb` | **算法原样保留** | 只加泰拉特有的乘数 |
| 实时播放节奏 | **原样保留** | `yearSec = 分钟 × 60 / e0` |

## 5. 原作里刻意保留的设计细节

1. **国家不可指定**（原作 FAQ 明确说明「出生国家不能固定」）。
   本作保留了随机抽签，同时提供了显式选择作为可玩性妥协。
2. **「过去的人生」存在浏览器本地**，不跟随账号迁移。本作用 `localStorage`。
3. **暂停、倍速、下一个决定**只在人生开始后可用 —— 本作一致。
4. **自动模式**：原作在宽屏顶栏、窄屏折叠进 `⋯`。本作放在顶栏。
5. **报告在同一页的人生末尾出现**，给年龄、死因、地图和曲线。本作给年龄、死因、
   四维曲线、结晶率曲线、净资产曲线与一生纪要。

## 6. 未移植的部分

- **过去 / 未来 / 任意时代**：原作需要额外的 `era.js`，本作只做「当下」。
- **地图**：原作报告里有地图，本作以城市名与迁徙次数代替。
- **多语言**：原作有 5 种语言（en/ko/ja/zh/vi），本作只做简体中文。
  文本层 `TL.L` 保留了 tagged-template + 词条表的完整接口，
  `TL.I18N` 挂上词条表即可切换。

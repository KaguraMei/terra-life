# 突然死亡系统说明

每年年末，系统会进行一次死亡判定。它先根据年龄生命表得到基础死亡率，再叠加体质、贫富、疾病、生活习惯、职业、战争、矿石病、种族和大事件等修正，得到这一年的死亡概率。

随后系统进行一次随机抽签：

- 没有命中：进入下一年；
- 命中：立即结束人生，并按年龄、地区、阶层和个人状态抽取死因。

因此，15 岁死亡并不代表触发了某个隐藏的必死事件。它可能只是当年死亡概率被随机命中；青少年死亡率通常较低，但不是零。天灾、战争、处决、矿坑事故等剧情事件也可能直接致死，这类死亡会单独标记为“事件直接致死”。

旧版本的死因表有一个名为 `ocd` 的残差类别，50 岁以下曾显示为“其他原因”，这就是“15 岁 · 其他原因”的来源。现在该残差会在抽取前拆分为感染、意外、先天/儿童疾病等具体类别，报告也会显示死亡属于年度风险判定还是事件直接致死。

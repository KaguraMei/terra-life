# 泰拉大事件年表（泰拉历 1000 – 1099）

本文收录 12 个国家与边境地带的大事件，覆盖原作主线段（约 1094–1101）之前
约一百年。它是 `js/data/timeline.js` 的数据来源。

---

## 0. 怎么读这份表

每一条都写成三段，第三段才是实现要用的：

| 段 | 含义 |
|---|---|
| **史实** | 发生了什么。这一段的措辞会被直接用于「报纸式」的旁白。 |
| **感知** | 谁能察觉。分三档：`亲历`（在本国且在场）· `邻国`（同大区，只听说）· `远方`（只剩一句船期新闻） |
| **效果** | 落到模型上的数字。词汇见下表。 |

### 效果词汇

| 键 | 含义 | 例子 |
|---|---|---|
| `war` | 该国战争风险增量（`+0.4` 即战争死亡率抬升 40%），可带 `dur` 持续年数 | 伦蒂尼姆事变 `war +0.55 / dur 3` |
| `cat` | 天灾频率增量 | 碎片大厦启动 `cat +0.8 / dur 2` |
| `ori` | 矿石病风险乘数增量 | 柯瓦尔矿场暴动 `ori +0.6 / dur 4` |
| `mort` | 全因死亡率乘数（不含 war/ori 覆盖的部分） | 大静谧 `mort ×1.35 / dur 6` |
| `money` | 一次性的财产冲击，单位是本国 `ppp` 的倍数 | 城市失陷 `money -4` |
| `tol` | 感染者容忍度位移（正数为更宽容） | 特锦赛起义 `tol +8` |
| `move` | 强制迁徙：把角色挪到本国另一座城市或沦为流民 | 停泊事变 `move refugee` |
| `die` | 直接致死概率 | 城内混战 `die 0.04` |
| `flag` | 打一个可被后续事件读取的标记 | `flag purged` |

### 三条实现原则

1. **大事件不取代人生，只改写人生的背景。** 玩家的死因里「天灾」不该被
   「伦蒂尼姆战役」挤掉 —— 后者只在玩家确实身处那座城市时才可能致命。
2. **远方的事件也必须留下痕迹。** 一个生在汐斯塔的人不会亲历四皇会战，
   但他会在某一年的物价里感觉到它。所以每条远方事件至少给一句旁白，
   能挂上经济/风险修正的就挂。
3. **时间是可抽的。** 出生年份从一段区间里抽，不是固定的 ——
   你没法选择自己生在哪个时代，这本来就是人生模拟的第一条规则。

## 一、维多利亚（Victoria）

### 1031 ｜ 四皇会战与高卢覆灭

**史实**：维多利亚、莱塔尼亚、乌萨斯三国组建联军，彻底击溃并瓜分高卢帝国。
高卢的文化、领土、蒸汽工业与移动城邦技术被三方瓜分，维多利亚一跃成为泰拉第一霸权。

**感知**：全大陆。这是那一代人的分水岭。

**效果**
- 维多利亚：`money +3`、`war -0.2 / dur 20`、`flag hegemon`
- 莱塔尼亚：`money +2`、`flag arts_legacy`（获得高卢法术与乐律遗产）
- 乌萨斯：`money +1`、`war -0.1 / dur 15`
- 其他国家：一句旁白 + `money -0.5`（高卢的订单没了）

### 1072 ｜ 塔拉大起义

**史实**：塔拉地区（原德拉克领地）爆发反抗维多利亚同化政策的武装起义。
维多利亚军方严酷镇压，爱德华·亚历山德莉娜（塔拉德拉克末裔血脉）被秘密处决。

**感知**：维多利亚 `亲历`；莱塔尼亚、叙拉古 `邻国`；其余 `远方`。

**效果**
- 维多利亚：`war +0.35 / dur 3`、`mort ×1.15 / dur 3`
- 若角色种族为 `draco` 且生于维多利亚：追加 `h -12`、`flag tara`，
  并额外触发一次「你家被查过」的旁白
- 全国：`tol -3`（镇压期的连带收紧）

### 1077 ｜ 二十一人公爵会议与弑君事件

**史实**：维多利亚末代正统君王（亨利皇子）在议会被各派系公爵联合签署绞刑判决
并处决。此后中央王位空悬二十余年，维多利亚陷入各大公爵分地割据的「摄政期」。

**感知**：维多利亚 `亲历`；全大陆 `远方`（但这条新闻足够大）。

**效果**
- 维多利亚：`war +0.25 / dur 22`（长期割据）、`money -1.5`、
  `flag interregnum`（此后二十年该国的国家援助与治安类事件减弱）
- 全国旁白：一句关于「王位空了」的新闻

### 1098 ｜ 伦蒂尼姆事变与萨卡兹进驻

**史实**：摄政王特雷西斯率萨卡兹军事委员会，应开国大公爵派系之邀进驻首都伦蒂尼姆，
全面戒严并接管城市防务。

**感知**：维多利亚 `亲历`；其余 `远方`。

**效果**
- 维多利亚：`war +0.45 / dur 2`、`tol -10 / dur 2`、`money -1`
- 若角色**就在伦蒂尼姆**且为感染者：`flag martial_law`，
  追加 `h -14`，并提高 `ori_arrest` 的年度触发率
- 若角色种族为 `sarkaz`：`h +6`（城里的同族忽然多了）但 `so -6`

### 1098–1099 ｜ 碎片大厦启动与伦蒂尼姆战役

**史实**：萨卡兹激活天灾武器「碎片大厦」，伦蒂尼姆城内自救军、各大公爵联军、
罗德岛以及深池部队爆发全面混战，城市大部分工业设施受创。

**感知**：维多利亚 `亲历`；莱塔尼亚、叙拉古 `邻国`。

**效果**
- 维多利亚：`war +0.6 / dur 2`、`cat +0.7 / dur 2`、`money -3`、`mort ×1.25 / dur 2`
- 身在伦蒂尼姆：`die 0.045`（逐年），存活者 `flag ruins`，`money -4`
- 若角色是罗德岛干员：`flag rhodes_lungmen`，追加一段专属旁白

## 二、乌萨斯（Ursus）

### 1068 ｜ 血峰战役（第十次乌萨斯-卡西米尔战争）

**史实**：乌萨斯帝国主力与卡西米尔银枪天马于国境血峰爆发决战。
乌萨斯近卫军元老派系伤亡惨重，双方停战，军方新老贵族矛盾加剧。

**感知**：乌萨斯、卡西米尔 `亲历`；其余 `远方`。

**效果**
- 乌萨斯：`war +0.3 / dur 2`、`flag old_guard_hurt`
- 卡西米尔：`war +0.3 / dur 2`、`money -1`
- 两国：`mort ×1.12 / dur 2`；征兵类事件概率上升

### 1077 ｜ 大叛乱与旧贵族清洗

**史实**：乌萨斯帝国内部爆发平民起义与前线基层军官哗变，老皇帝下令内卫与纠察队
进行血腥清洗，大量军官及家属被流放至北原矿区。

**感知**：乌萨斯 `亲历`；其余 `远方`。

**效果**
- 乌萨斯：`war +0.5 / dur 3`、`tol -8 / dur 10`、`mort ×1.3 / dur 3`
- 乌萨斯境内角色：`die 0.035`；存活者 `money -2`
- 若家境分位 `q >= 4`（军官家庭）：强制 `move` 至北原，`flag exiled`，
  `money -4`，`h -18` —— 这一条对应「大量军官及家属被流放至北原矿区」

### 1089 ｜ 柯瓦尔矿场暴动

**史实**：北原柯瓦尔矿场爆发感染者矿工抗税与反虐待暴动，当地守军残暴镇压，
催生了后续荒野反抗武装（整合运动雏形）的联合。

**感知**：乌萨斯 `亲历`；雷姆必拓、卡兹戴尔 `邻国`。

**效果**
- 乌萨斯：`ori +0.5 / dur 5`、`tol -4`
- 乌萨斯境内感染者：`h +8`（有人先站出来了）、`so +6`、
  `flag reunion_seed`（提高日后被整合运动招募的概率）
- 若角色职业为 `oriminer` / `miner` / `slave`：`die 0.03`

### 1096.12 ｜ 切尔诺伯格停泊事变

**史实**：切尔诺伯格核心城在天灾降临之际人为关闭逃逸引擎，整合运动趁乱全面攻占城市；
其后核心城被设定冲撞炎国移动城邦龙门，险些引爆两国全面战争，最终核心城废弃。

**感知**：乌萨斯、炎国（龙门）`亲历`；全大陆 `远方`。

**效果**
- 乌萨斯：`war +0.5 / dur 3`、`cat +1.2 / dur 1`、`money -2`
- **身在切尔诺伯格**：`die 0.10`（这是本作致死率最高的一条）；
  存活者 `move refugee`、`money -4`、`hl -20`、`flag cherobog`
- 龙门：`war +0.4 / dur 2`、`money -1`、`tol -6`（感染者被大规模排查）
- 若角色是罗德岛干员：`flag rhodes_cherobog`，追加专属旁白
- 全大陆：一句新闻 + `ori +0.1 / dur 2`（感染者恐慌）

## 三、炎国（Yan）

### 约 1000 年前 ｜ 大荒落之役

**史实**：炎国朝廷联合天师府、禁军于大荒落地区围剿远古巨兽「岁」，
将其本体斩碎分化为十二枚具有独立意识的碎片，确立了朝廷对境内所有巨兽实体的
监管体系（司岁台制度确立）。

**感知**：炎国 `亲历`（作为立国传说，每一年都可能被提起）；其余 `远方`。

**效果**：生在炎国的角色，在童年有一次「听老人讲岁兽」的旁白机会，
`sm +2`、`so +2`。不产生任何风险修正 —— 它是传说，不是新闻。

### 1097 ｜ 尚蜀器物活化事件

**史实**：尚蜀城内发生由「岁」之碎片（望、夕、令）牵扯的机关术与古卷化形异动，
司岁台与天师府全面介入收缴异宝，尚蜀行政区解除封锁。

**感知**：炎国 `亲历`；东国、龙门 `邻国`。

**效果**
- 炎国：`money -0.8`、`h -4`（物价与管制）
- 身在尚蜀：`flag artifact`；若角色技艺适应性 `arts >= 60`，
  `arts +6`、`h +6`（你摸到过不该摸的东西）
- 若角色职业为 `witch` / `caster` / `artsmith`：额外一段旁白

### 1098 ｜ 玉门关塞防卫战

**史实**：边陲军事移动城邦玉门遭遇山海众残党破坏动力核心，关外荒原巨兽残余威能异动，
玉门守将与江湖游侠协同平息关隘危机。

**感知**：炎国 `亲历`；乌萨斯、萨米 `邻国`。

**效果**
- 炎国：`cat +0.5 / dur 1`、`war +0.2 / dur 1`
- 身在玉门：`die 0.02`；若角色职业为 `soldier` / `guard` / `mercenary`，
  `h +8`、`money +1`（守将有赏）

### 1099 ｜ 大荒城司农寺农牧危机

**史实**：大荒城天师府与司农寺在大规模地脉源石治理与旱稻试验中遭遇阻力，
牵扯出「岁」长兄有关的阵局变动。

**感知**：炎国 `亲历`。

**效果**
- 炎国：`money -1`、`ori +0.15 / dur 3`（地脉治理失败的代价）
- 炎国境内荒野角色：`flag famine_risk`，追加一次饥荒判定

## 四、卡西米尔（Kazimierz）

### 约 1050 年代 ｜ 商业联合会建立与骑士阶层重构

**史实**：资本财阀建立商业联合会，逐步架空传统的国民院与大骑士长权限，
骑士头衔与武力被全面包装为商业竞技娱乐产业。

**感知**：卡西米尔 `亲历`；其余 `远方`。

**效果**
- 卡西米尔：`money +1.5`、`war -0.2 / dur 25`、`tol -2`
- 卡西米尔境内：`knight` 职业的收入上升、`stand` 行为改变；
  平民出身的角色多一条「去看比赛」的旁白

### 1072 ｜ 临光家族「黜落」风波

**史实**：大骑士领征战骑士名门临光家发生长子夫妇失踪事件，家族受到商业联合会排挤，
玛嘉烈·临光被暗中打压。

**感知**：卡西米尔 `亲历`。

**效果**：`h -3`（一条让人不安的新闻）。若角色是 `knight`：`money -0.5`、`h -6`。

### 1094 ｜ 耀骑士流放

**史实**：玛嘉烈·临光在竞技场公开确诊感染矿石病，商业联合会与监正会依律
剥夺其骑士称号并将其逐出卡西米尔国境。

**感知**：卡西米尔 `亲历`；全大陆 `远方`（这是感染者议题第一次上头条）。

**效果**
- 卡西米尔：`tol -5 / dur 4`
- 卡西米尔境内感染者：`h +6`（有人替他们站着）、`so +4`
- 卡西米尔境内 `knight` 职业且已感染：`flag disgraced`，`money -2`

### 1097 ｜ 第二十四届特锦赛与感染者大起义

**史实**：流亡骑士玛嘉烈回归夺冠，同时期大骑士领地下爆发以「红松骑士团」为核心的
感染者地下暴动，大骑士领断电陷入混乱，商业联合会最终妥协开放有限劳工权益。

**感知**：卡西米尔 `亲历`；全大陆 `远方`。

**效果**
- 卡西米尔：`war +0.4 / dur 2`、`money -2`、`tol +8`（这是全表唯一一次容忍度上升）
- 大骑士领境内：`die 0.03`；感染者存活者 `h +14`、`so +8`、`flag redpine`
- 全大陆感染者：`h +4`（新闻传得很远）

## 五、哥伦比亚（Columbia）

### 1019 ｜ 独立战争与拓荒宪章

**史实**：哥伦比亚脱离维多利亚殖民地身份宣布独立建国，发布鼓励全民开拓荒原的
《拓荒法案》，科技公司与拓荒兵团开始大肆向西扩张。

**感知**：哥伦比亚 `亲历`；维多利亚 `邻国`。

**效果**
- 哥伦比亚：`money +1`、`cat +0.3 / dur 20`（拓荒就是往天灾里走）
- 哥伦比亚境内荒野角色：`ori +0.2 / dur 15`

### 1070s–1080s ｜ 工业淘金热与山地开拓潮

**史实**：源石精炼技术与硅基科研大突破，雷神工业、莱茵生命等巨头成立，
原住民部族及流民被驱离至荒野边境。

**感知**：哥伦比亚 `亲历`；全大陆 `远方`。

**效果**
- 哥伦比亚：`money +2`、`tol -3`、`ori +0.2 / dur 10`
- 哥伦比亚境内荒野角色：`move` 概率上升，`flag displaced`
- 全大陆：`money +0.5`（技术红利外溢）

### 1099 ｜ 「孤星」计划与破天事件

**史实**：莱茵生命总辖克里斯滕·弗里斯顿在特里蒙外空研究基地启动高空能量武器，
击穿了笼罩在泰拉上空的「静止天空（星荚）」，泰拉文明首次观测到宇宙深空与真实星海。

**感知**：**全大陆同时**。这是本表里唯一一条所有人都抬头看见了的事件。

**效果**
- 全国：`h +10`（一次性的集体震动，不分国籍与阶层）
- 哥伦比亚：`money +2`、`flag starfall`
- 所有角色：写一条特殊旁白 —— 这一条值得单独写，因为它是「所有人都记得自己
  那天在哪里」的那种事件
- 若角色是 `scholar` / `teacher` / `journalist` / `caster`：`sm +4`、`h +6`

## 六、萨卡兹 / 卡兹戴尔（Kazdel）

### 远古至近代 ｜ 六次毁灭与重建

**史实**：卡兹戴尔城邦在历史上先后经历过六次被周边各国（莱塔尼亚、维多利亚等）
组成的「剿灭同盟」彻底焚毁摧毁的记录。

**感知**：萨卡兹角色 `亲历`（作为家族记忆）；其余 `远方`。

**效果**：出生在卡兹戴尔或种族为 `sarkaz` 的角色，童年有一次「听长辈讲第六次」
的旁白，`h -6`、`so +4`（同族的联结更紧）。基线层面已经体现在
`nations.js` 的 `KDZ` 参数里（`le 60`、`ori [0.60, 0.80]`）。

### 1086 ｜ 巴别塔组织成立

**史实**：特蕾西娅在卡兹戴尔荒原发掘出陆行舰「罗德岛」，并以此建立军事兼人道组织
「巴别塔」，尝试通过探索源石本质来打破萨卡兹的世仇宿命。

**感知**：卡兹戴尔 `亲历`；全大陆 `远方`。

**效果**
- 卡兹戴尔：`tol +5`、`h +4`、`flag babel`
- 全大陆萨卡兹角色：`h +5`（有人在做一件不一样的事）
- 若角色技艺适应性 `arts >= 70` 且尚未加入罗德岛：提高罗德岛招募概率

### 1094 ｜ 卡兹戴尔斩首行动

**史实**：特雷西斯派系的刺客与雇佣兵突袭巴别塔旗舰，特蕾西娅遇刺身亡，
巴别塔组织崩溃瓦解，特雷西斯全面掌控卡兹戴尔与军事委员会。

**感知**：卡兹戴尔 `亲历`；全大陆 `远方`。

**效果**
- 卡兹戴尔：`war +0.5 / dur 5`、`h -14`、`flag babel_fell`
- 全大陆萨卡兹角色：`h -10`、`so -4`
- 若角色是罗德岛干员：`h -16`，追加专属旁白
- 若角色仍在巴别塔（`flag babel`）：`die 0.08`

## 七、莱塔尼亚（Leithanien）

## 十三、实现要点

### 日历

游戏现在从第 0 年开始，需要改成泰拉历。方案：

```js
// 出生年份从区间里抽（默认 1040–1090，加权偏向 1050–1080）
S.bornYear = TL.drawBirthYear(TL.rnd);
S.year = S.bornYear + Math.floor(S.age);
```

这样大部分人生会覆盖 1086–1099 这一段密集期，但每次抽到的时代不同 ——
「你没法选择自己生在哪个时代」本来就是这游戏的第一条规则。

### 触发

在 `TL.endYear` 的末尾（排程之前）插入一次 `TL.timelineYear(S)`：

```js
TL.timelineYear = function (S) {
  for (const ev of TL.TIMELINE) {
    if (ev.year !== S.year) continue;
    if (S.flags['tl_' + ev.id]) continue;      // 一辈子只响一次
    S.flags['tl_' + ev.id] = 1;
    TL.fireTimeline(S, ev);
  }
};
```

### 三档感知的判定

```js
function感知(ev, S) {
  if (ev.nations.indexOf(S.nation) >= 0) return ev.local || 'here';   // 亲历
  if (ev.regions && ev.regions.indexOf(n.reg) >= 0) return 'near';    // 邻国
  return 'far';                                                       // 远方
}
```

### 与现有系统的接口

| 现有字段 | 时间轴如何改它 |
|---|---|
| `n.war` | 加一个 `S.tlWar` 增量，`deathProb` 读 `n.war + tlWarAt(nation, year)` |
| `n.cat` | 同上，`S.tlCat` |
| `TL.oriLifetimeP` | 乘 `1 + tlOriAt(nation, year)` |
| `TL.tolOf` | 加 `tlTolAt(nation, year)` |
| `S.money` | 一次性冲击直接扣 |
| `TL.NATION_BY_ID[...].le` | **不改**。大事件不该重算生命表 —— 那是长期结构，事件是短期冲击 |

最后一条很重要：**生命表是慢变量，事件是快变量。** 四皇会战不会改变
维多利亚人的生理寿命，它只改变那几年谁死了、谁破产了、谁搬走了。
把事件做进 `q(x)` 会让模型失去可解释性。

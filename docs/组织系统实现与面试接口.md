## 职业闭环

1. 招募事件展示一个符合资格的组织岗位，玩家选择申请、暂缓或拒绝。
2. 招募、罗德岛旧入口、整合运动邀请以及历史/职业转任均接入四题面试（3 道组织题 + 1 道岗位题）。按三项倾向与综合匹配度判定，不再追加概率录用；共 106 道题、34 个岗位题库。未录用前保留原职业。
3. 入职记录组织、路线、当前等级、任职年份、原职业和完整履历。部分路线会转为警员、竞技骑士、市政官员等对应职业。
4. 每个组织提供两种专属工作事件，共 36 条。与人物互动共用每年的一个既有事件位置，仍受冷却、次数和触发条件限制。
5. 按任职年限逐级晋升，同一年最多升一级。普通组织每级工资加成 8%，上限 24%；罗德岛沿用干员工资倍率，不叠加两份组织加成。整合运动无固定工资，晋升也不增加工资；营地口粮仅抵扣基本生活费。
6. 加入满三年后可遇到职业去留抉择，之后间隔六年。全部路线均可留任或离职；佣兵、巴别塔、军事委员会、骑士、近卫局、旧家族等另有符合条件的转任选项。其余跨组织流动通过离职后重新招募完成。
7. 失业、转行、退休、入学、应征服役、迁出辖区会同步结束组织身份；离职立即更新收入，履历保留。一般离职/考核失败三年后可再次申请，候补一年，暂缓两年，直接拒绝八年。招募事件本身另有五年冷却，故冷却结束不保证马上收到邀请。
8. 人生报告显示历任组织、最高组织等级、离职原因和人物往来，离职后也能看到。

本轮工作事件以叙事和属性反馈为主，历史转折与职业去留使用可选抉择；尚未为每种任务设计多阶段任务链。

## 历史与人物

已接入 15 个组织转折：莱茵生命 1095/1097/1099、龙门近卫局 1097、佣兵 1086/1094、巴别塔 1094、军事委员会 1098、竞技骑士 1094/1097、司岁台 1097、两支拉特兰路线 1099、喀兰贸易 1097、叙拉古家族 1099。

转折优先于日常组织任务；只有在该历史节点前加入的成员会遇到去留选择。巴别塔解体不允许继续留任。叙拉古成员可留在原城继续家族事务、符合资格时转新城市政，或离职；新城市政任职会迁往新沃尔西尼。旧整合在 1096 年结算切城事件后自动结束编制、留下履历，不提供无限留任选项。

**1099 年起仅新沃尔西尼禁止家族介入。** 家族路线在其他叙拉古城市仍可经引荐加入、晋升；迁入新沃尔西尼会结束家族身份。没有具名家族的路线不代表贝洛内等已覆灭家族复活。

人物往来按组织、年份、等级与概率开放。例如博士、阿米娅，陈、星熊、诗怀雅，塞雷娅、克丽斯腾、缪尔赛思、多萝西，左乐、伺夜、拉维妮娅等。每个人至少间隔四年、最多互动三次；并非加入就必然遇见。年度人物机会按符合条件者的权重求和、封顶 20%，随后按权重选人；该机会还受事件冷却与排程时状态变化影响。

关键出场限制：塞雷娅在莱茵生命的互动截止 1094 年、陈在近卫局截止 1096 年、克丽斯腾截止 1098 年。一般人物互动的 1110 年上限是保守的游戏截断，**不是人物死亡年份**。梅兰德采用普通项目联络员，不把古老创始人放进现代随机互动。

## 资料依据与二次创作边界

本轮核对的 PRTS 条目：

- [组织总表](https://prts.wiki/w/泰拉大典:组织)：组织名称及所属关系。
- [莱茵生命](https://prts.wiki/w/泰拉大典:组织/莱茵生命)：1085 公司化、1092 科室扩展、炎魔及弧光相关节点。
- [龙门近卫局](https://prts.wiki/w/泰拉大典:组织/龙门近卫局)：近卫局职能、陈离任及诗怀雅后续职责。
- [其他组织](https://prts.wiki/w/泰拉大典:组织/其他)：梅兰德基金会（Maylander Foundation）等。
- [叙拉古](https://prts.wiki/w/泰拉大典:地理/叙拉古)：1099 新沃尔西尼及其管理变化。

招募门槛、等级称谓、晋升年限、工资、任务台词、人物互动文本、概率、面试画像均为同人游戏规则，不是官方招聘制度或原文引用。部分组织只确认存在，未核实准确成立年：例如黑钢 1090、企鹅物流 1094、喀兰贸易 1095，以及军事委员会的 1094 招募窗口，都不应当作成立年份；军事委员会在更早年代已经活动。其余历史节点沿用项目年表，尚不能声称逐项完成了全部剧情原文校验。

数据中的 `source` 指向资料入口，`rulesSource: 'project-rule'` 标明游戏规则，`yearBasis` 区分项目窗口与年表依据。细化考据时应先调整数据，不在事件中另写一套年份判断。

## 面试接口与后续内容

组织数据位于 `js/data/organizations.js`，生命周期位于 `js/engine/organization.js`，工作与历史抉择位于 `js/data/organization-events.js`。正式题库位于 `js/data/interviews.js`，校验、抽题、评分及抉择桥接位于 `js/engine/interview.js`。

使用 `tryJoinOrganization()` 发起面试，问答通过 `afterDecision` 逐题推进。结束时复核年份、原组织和当前资格，再兑现录用；重复、未完成或与实际评分不符的结果不能录用。所有结果记录在 `orgInterviewHistory` 并进入人生报告。

字段规则、注册接口、JSON Schema、可执行题库扩展示例与测试命令见[面试题库格式与DLC约束](面试题库格式与DLC约束.md)。黑钢、企鹅物流、喀兰贸易、雷神工业的深化，以及鲤氏侦探事务所、深海猎人、独立红松骑士团的新路线，按[组织 DLC 更新计划](组织DLC更新计划.md)逐包推进。

## 验证

```bash
node tools/verify.mjs
node tools/verify-reliability.mjs
node tools/verify-birth.mjs
node tools/verify-organizations.mjs
node tools/verify-interviews.mjs
node tools/verify-events.mjs 1000
```

专项检查覆盖全部 34 路线的资格和归属、32 条新增路线的真实排程招募、同年重复晋升、退出即时收入、历史转职/解体、人物离任窗口与冷却、报告快照、面试重复结果与资格变化、多题衔接。

浏览器检查可先启动本地服务，再执行 `node tools/verify-organizations-ui.mjs <Playwright模块路径> <本地URL>`；省略参数时使用已安装的 `playwright` 和 `http://127.0.0.1:8814/`。默认浏览器为 Edge，可用环境变量 `TERRA_BROWSER_CHANNEL` 修改。检查真实招募按钮、晋升显示、家族转市政按钮、正式四题面试与多题接口、离职后履历/人物报告，以及 1440、390、320 像素布局。截图输出到系统临时目录，浏览器自动关闭。

1000 局固定种子模拟及 73 项构造事件检查结果见[事件可达性报告](事件可达性报告.md)。构造状态通过证明接线可执行，不等于每条路线在随机人生中都常见。

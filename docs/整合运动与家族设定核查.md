# 整合运动与家族设定核查

更新：2026-10-19。结论：旧实现的永久跨国招募、警卫工资和全国性家族停招均不合适，现已调整。

## 设定依据

本轮通过 PRTS MediaWiki API 读取以下条目的正文：

| 资料 | 核对结果 | 实现位置 |
| --- | --- | --- |
| [整合运动](https://prts.wiki/w/泰拉大典:组织/整合运动) | 起初在乌萨斯荒原召集感染者；南下后理念与内部状况改变。1096 年占领切城，有杀害非感染者的记载。切城—龙门事件后旧指挥体系覆灭，九后来重组整合并前往维多利亚继续活动 | `organizations.js`、`organization.js` 的旧路线窗口；`timeline.js` 的在场袭击分支 |

没有从这些资料确认整合存在固定工资制度。“零固定工资＋有限实物口粮”是本作对营地生存的建模，不是官方工资表。引荐、问答分数、时间窗和伤亡概率也属于游戏设计。

## 切尔诺伯格平民何时会遇到邀请

1. 年份在 **1094—1095**、人在乌萨斯、年龄 15—64 岁，已感染，且未加入其他组织、未在校/服役/退休/监禁/为奴。
2. `reunionLean > 0.5` 才能抽到接触事件。倾向受污名、歧视、家境、幸福、病情公开程度、治疗与逮捕环境影响。这是事件资格，并非必然触发概率。
3. 接触事件记录年份，随后最多两年内、仍满足组织和年份条件，才会出现邀请。高倾向本身不再绕过接触。
4. 问答表现为**营地接纳**，讨论口粮、撤离与同行底线；无需警卫职业资格。它只代表这条小营地路线，不能代表整合全体派系。通过后才获得身份与训练加成。

未感染平民不能通过这条路线加入。**1096 年事变期间，无论健康平民、感染者还是流民，都不会出现这套营地接纳流程。** 拒绝此前的邀请不会触发处决；原举报选项仍可能造成健康损失。

## 是否可能被整合杀死

会。1096 切城历史事件对**身在切尔诺伯格、国别为乌萨斯、尚未流离的居民**触发一次直接风险判定，维持原来的 **10%**，不再另叠一轮袭击抽样。

- 对非整合成员，命中后等概率分为天灾（`cat`）或整合武装杀害平民（`hom`）：即这一历史分支各约 5%。感染者也没有绝对豁免。
- 旧整合成员不套用“被当成平民杀害”的分支，命中时按天灾处理；这不是对组织成员设定全程安全。
- 日志记录地点、加害方或灾害，死亡触发来源为 `timeline:urs_cherobog`。不再只有模糊的“其他原因”。
- 先结算在场风险，生还者才逃离，记录原居地并进入荒野流民营地，避免一边已逃走一边仍算切城居民。

10% **不是该年全部死亡概率**。原有年度死亡、矿石病、健康和战争环境风险仍独立存在。这里的概率是玩法参数，不能当作官方居民生还率。

## 旧整合何时结束，工资如何处理

游戏按年推进，把 1096 年切城—龙门战局折叠成同一个历史节点。因此旧路线有效年设为 1094—1095（`untilYear: 1095`，含末年），进入 1096 后停止招募、任务、晋升和旧编制身份。1094 是既有项目的保守出场窗口，并非本轮考据确认的成立年。

旧成员自动结束履历并转为待业；旧旗标、跨年未完成问答不能让身份复活。**九领导的新整合仍存在，但本轮没有实现可加入的后继路线，也不会把旧营地自动变成新整合。** 将来需要独立地域、年表、人物与题库。

成员固定工资为 0，晋升仍为 0。口粮每年抵扣 `国家 ppp × 0.52` 的基本生活费用，不存入现金、不形成资产，不覆盖额外家属开销与治疗费。界面明确显示营地补给，生计分位包含口粮价值。离开后补给立即失效，收入按新的职业状态重算。底层 `guard` 仅复用行动职业模型，不意味着是受薪警卫。

## 家族如何加入与延续

原通用招募入口遇到家族时，改为熟人引荐，记录当年引荐身份，随后进行**家族试探**。无引荐不能直接调用加入；引荐有效三年，仍需满足职业、地区等门槛。题目中的保密和风险评分表示该路线的适应度，不是认可家族命令正当。

1099 年起，新沃尔西尼禁止家族招募、任职；迁入者结束家族身份。其他叙拉古城市继续允许引荐、任职和晋升。原有成员可在历史去留中留下、退出或申请转新城市政；通过后才迁城、切换身份。路线保持泛指家族，不宣称已覆灭的具名家族仍在招聘。

## 回归验证

`node tools/verify-faction-boundaries.mjs` 检查年份/国别/感染/接触矩阵、15 岁拒绝邀请、实际问答入会、零工资与口粮、旧组织结束、过期问答、家族引荐与新城禁入、切城两类死因、逃离和事件防重。

组织、题库、可靠性、结构与完整人生模拟沿用原专项脚本；既有构造场景同步补齐真实接触/引荐条件，没有跳过这些路线。
